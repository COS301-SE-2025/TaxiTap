## <img src="https://api.iconify.design/mdi/target.svg?color=%23FF9900" width="32" height="32"/> Project Overview

TaxiTap transforms South Africa's minibus taxi industry through digital innovation. Features include real-time tracking, location-aware booking, flexible routing, digital communication (no hooting), and comprehensive rating systems.

## <img src="https://api.iconify.design/mdi/rocket-launch.svg?color=%23FF9900" width="32" height="32"/> Getting Started

### <img src="https://api.iconify.design/mdi/download.svg?color=%23FFB74D" width="28" height="28"/> Installation

```bash
# Clone repository
git clone https://github.com/COS301-SE-2025/TaxiTap.git
cd TaxiTap

# Install dependencies
npm install

# Start development server
expo start
```

### <img src="https://api.iconify.design/mdi/cog.svg?color=%23FFA500" width="28" height="28"/> Prerequisites
- Node.js (v18 or higher)
- npm or yarn package manager
- Expo CLI (`npm install -g expo-cli`)
- Android Studio (for Android development)
- Xcode (for iOS development - macOS only)

### <img src="https://api.iconify.design/mdi/play-circle.svg?color=%23FFD93D" width="28" height="28"/> Running the App

```bash
# Android
expo run:android

# iOS (macOS only)
expo run:ios

# Web
expo start --web
```

For detailed setup instructions, see the [Installation Manual](https://github.com/COS301-SE-2025/TaxiTap/blob/dev/docs/COS%20301%20-%20Technical%20Installation.pdf).

- <img src="https://api.iconify.design/mdi/code-tags.svg?color=%23FFA500" width="22" height="22"/> `dev` - Integration branch for features
- <img src="https://api.iconify.design/mdi/star-circle.svg?color=%23FFD93D" width="22" height="22"/> `feature/*` - New feature development
- <img src="https://api.iconify.design/mdi/alert-circle.svg?color=%23FF9900" width="22" height="22"/> `hotfix/*` - Critical bug fixes
- <img src="https://api.iconify.design/mdi/package-variant.svg?color=%23F39C12" width="22" height="22"/> `release/*` - Release preparation
